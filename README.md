# Generador 3D con IA (Streamlit & GLB)

Aplicación web desarrollada en **Streamlit** que permite generar modelos 3D interactivos en formato `.glb` mediante Inteligencia Artificial. Incluye un visor 3D integrado en el navegador usando Google `model-viewer`.

## 🚀 Despliegue rápido en Streamlit Cloud
1. Sube estos archivos a un repositorio público en GitHub.
2. Ve a [share.streamlit.io](https://share.streamlit.io/).
3. Conecta tu repositorio de GitHub, selecciona el archivo `app.py` y haz clic en **Deploy**.
